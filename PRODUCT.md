# Transfer

Transfer is a Paseo plugin for developers who want to continue a workspace on another host. Tom requested a maintained replacement for paseo-plugin-sync, updated to current Paseo, simplified using current features, tested with real transfers, and described in the same concise style as his other plugins.

The primary entry point is a Transfer button at the top right of each workspace. It opens a popup with that workspace already selected; the sidebar is hidden by default and can be enabled in Display settings. Command Center keeps the full transfer screen available. The primary task is selecting a source workspace, a connected Paseo host and new directory, previewing the transfer, then copying or moving. Copy preserves the source. Move archives it only after verification. Git history, local changes, and Claude/Codex conversations travel together. This is a one-shot transfer, not continuous synchronization.

The plugin runs inside Paseo on desktop, web, iOS, and Android. The default transport reuses authenticated Paseo connections with Transfer installed on both hosts. SSH remains an advanced alternative requiring only one installation. Keep the app open during connected transfers; closing the popup preserves progress. Home and system directory workspaces are refused. Both transports target Linux/macOS environments. It inherits Paseo's theme and app chrome. Loading, no available workspaces, SSH failure, stale previews, active agents, occupied destinations, verification failure, and partial transfer are explicit product states.

Git history scope is chosen for each transfer and shown in its preview. **Full repository** remains the default and includes all local branches, tags and HEAD. **This workspace** explicitly includes only the current branch/HEAD and complete ancestor history, including unpublished commits; other branches and all tags stay on the source. Detached HEAD keeps its full ancestry without a branch. Files, index changes and conversations are complete in either mode, and non-Git folders are unchanged. A selected missing object or shallow history blocks export. This choice supports a complete released leaf in a shared partial clone without implying that unrelated refs or their owners can move. Transfer never fetches or repairs the source to make an export pass; endpoints must explicitly support the scoped capability.
